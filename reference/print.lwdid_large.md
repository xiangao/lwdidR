# Print a large-N lwdid object

Print a large-N lwdid object

## Usage

``` r
# S3 method for class 'lwdid_large'
print(x, digits = 4, ...)
```

## Arguments

- x:

  An object of class `"lwdid_large"` from `lwdid(..., method=)`.

- digits:

  Number of digits for the results table.

- ...:

  Ignored.

## Value

Invisibly returns `x`.
