# Event-study plot for a large-N lwdid object

Plots WATT(r) against relative time r with simultaneous (sup-t)
confidence bands. Requires the ggplot2 package.

## Usage

``` r
# S3 method for class 'lwdid_large'
plot(x, ...)
```

## Arguments

- x:

  An object of class `"lwdid_large"` from `lwdid(..., method=)`.

- ...:

  Ignored.

## Value

A `ggplot` object.
